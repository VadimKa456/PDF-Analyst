# Final quality checklist

Before delivering the analysis, confirm:

- [ ] Every file named as reviewed was actually accessible and inspected.
- [ ] Scope, entity, version and period are identified where relevant.
- [ ] Every material finding has a real source locator.
- [ ] PDF page index and printed page number are not confused.
- [ ] Printed values are distinguished from calculated values.
- [ ] Calculations show the formula, inputs, unit and period.
- [ ] Comparisons align entity, scope, period, unit and basis.
- [ ] Contradictions are not merely scope or version differences.
- [ ] OCR uncertainty and extraction gaps are disclosed.
- [ ] No missing value has been silently treated as zero.
- [ ] No unsupported claim is presented as established fact.
- [ ] Conclusions answer the user's question without unnecessary filler.
- [ ] Limitations and unreviewed material are stated explicitly.
