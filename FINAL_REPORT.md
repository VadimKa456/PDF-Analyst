# PDF Analyst — финальный отчёт

**Дата:** 16.11.2026  
**Версия:** 1.1.0  
**Статус:** рабочее локальное приложение; сервер запущен на `http://127.0.0.1:8000`

---

## 1. Что реализовано

Полный сквозной путь **UI → API → обработка → БД → UI**:

- загрузка нескольких PDF в проект;
- извлечение текста, страниц, таблиц, чисел, единиц, валют и периодов;
- OCR сканированных страниц (Tesseract + OpenCV, русский и английский);
  построчный проход `image_to_data`, адаптивная бинаризация, deskew, повторный
  проход при низкой уверенности;
- восстановление таблиц из OCR по координатам слов; поддержка отрицательных
  сумм в скобках, кодов строк, повторяющихся групп колонок и единиц страницы;
- нормализация OCR-чисел: исправление подмен, восстановление разрядов,
  трактовка `6/` в конце числа как `7`;
- покрытие чисел: какие значения привязаны к показателям, а какие являются
  кодами, реквизитами, датами или годами;
- дашборд проекта: качество распознавания, покрытие данными, периоды,
  ключевые показатели, последние значения и проблемные документы;
- хранение показателей с документом, страницей, фрагментом и уверенностью;
- полнотекстовый поиск (SQLite FTS5);
- AI-аналитик с локальным детерминированным движком и опциональными
  OpenAI-совместимыми API / Ollama;
- RAG: поиск фрагментов, структурированные факты, проверка ответа LLM;
- сравнение документов и периодов, нечёткое и межъязыковое сопоставление
  показателей;
- расчёты абсолютных и процентных изменений, тренды, пропуски, противоречия,
  экстремумы, средние;
- интерактивные таблицы 7 типов;
- графики Plotly (line, bar, histogram, pie, stacked, scatter, heatmap);
- экспорт Excel, CSV, PDF-отчёт и PNG графиков;
- проекты (создание и удаление с полной каскадной очисткой БД и FTS-индекса), история анализов, настройки, асинхронная обработка с прогрессом;
- раздел «О программе»: версия 1.1.0, автор VADIJI | AI Creative Studio, e-mail vadiji.ai@gmail.com (данные приходят из `/api/health`);
- SPA-интерфейс, раздаваемый тем же FastAPI-сервером.

## 3. Инструкции по запуску

### Быстрый старт (Windows)

```bat
setup.bat
start.bat
```

`setup.bat` создаёт `.venv`, устанавливает зависимости, собирает frontend,
создаёт `.env` и проверяет Tesseract. `start.bat` запускает сервер и открывает
браузер.

### Ручной запуск

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
cd frontend
npm install
npm run build
cd ..\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

- Приложение: <http://127.0.0.1:8000>
- Swagger: <http://127.0.0.1:8000/api/docs>

### Настройка AI

В разделе **Settings**:

- `none` — только локальный движок (по умолчанию);
- `ollama` — локальная модель через Ollama;
- `openai` — OpenAI-совместимый API (ключ, base URL, модель).

Ключи маскируются в API и не логируются. В облако передаются только
структурированные факты и найденные фрагменты, а не PDF целиком.

**Проверка подключения.** Кнопка «Проверить соединение» показывает точную
ошибку и задержку. Если провайдер вернул `model_not_found`, приложение
загружает список доступных моделей и предлагает выбрать подходящую: у
агрегаторов имена моделей содержат префикс (`glm/glm-4.7`, `am/free`), поэтому
стандартное `gpt-4o-mini` может быть недоступно. Временные ответы провайдера
(`429`, `500`, `502`, `503`, `504`, а также `temporarily unavailable`)
повторяются до трёх раз с учётом `retry_after_seconds`. Модель эмбеддингов
проверяется отдельной кнопкой; при её недоступности семантический поиск
откатывается к FTS5 с предупреждением.

## 7. Незавершённое и ограничения

1. **Интерактивная проверка UI в браузере не выполнена.** Инструмент браузера
   был недоступен в текущей сессии. UI проверен TypeScript-сборкой, Vite-сборкой,
   HTTP-раздачей SPA и полным API E2E. Рекомендуется пройти по разделам
   Dashboard → Documents → Analyst → Compare → Tables → Charts → Reports →
   Settings вручную.
2. **Облачный AI проверен на реальном OpenAI-совместимом провайдере**
   (`https://anymodel.org/v1`): подключение, список моделей, чат, JSON-режим,
   повтор временных `503` и полный цикл AI-аналитика работают. Для этого
   провайдера стандартное имя `gpt-4o-mini` недоступно — используется
   `glm/glm-4.7`; модель эмбеддингов провайдер не предоставляет, поэтому
   семантический поиск остаётся выключенным (FTS5). Ollama в этом окружении
   не запускалась.
3. **OCR и таблицы — эвристические.** Качество зависит от скана, шрифта,
   разрешения и языка. Сложные многоуровневые таблицы могут требовать
   ручной проверки.
4. **PDF с паролем не поддерживаются.**
5. **Конвертация валют не выполняется.** Разные валюты не сравниваются без
   явного курса; выводится предупреждение.
6. **Семантический поиск через эмбеддинги опционален** и требует внешней
   модели; по умолчанию используется FTS5.
7. **Нет встроенной аутентификации.** Приложение рассчитано на локальный
   однопользовательский запуск. Не открывайте порт 8000 в интернет без
   reverse proxy, TLS и авторизации.
8. **Приложение не заменяет аудиторскую проверку.** Результаты и источники
   следует сверять с оригиналами документов.

## 8. Desktop-сборка (Windows 10/11)

- Готовый установщик опубликован в [GitHub Releases](https://github.com/VadimKa456/PDF-Analyst/releases/tag/v1.1.0):
  [`PDF-Analyst-Setup.exe`](https://github.com/VadimKa456/PDF-Analyst/releases/download/v1.1.0/PDF-Analyst-Setup.exe) (один `.exe`, 172 670 359 байт,
  SHA256 `69E661C2C7F5EB9AEFCEB6D6162A635396E42E8535052804727FCAB03CCE857E`; MIT-лицензия; логотип VADIJI; экспорт открывает системный диалог сохранения; OCR извлекает мелкие числа в узких колонках).
- Каталоги `dist/` и `build/` не коммитятся в Git (порождаемые артефакты); портативная версия `dist\PDF Analyst\PDF Analyst.exe` создаётся локально командой `build_desktop.bat`.
- Приложение работает в собственном окне (`pywebview` + Edge WebView2), а не в
  браузере. Данные упакованной версии — `%LOCALAPPDATA%\PDF Analyst\data`.
- Установщик запрашивает установку недостающих компонентов: WebView2 и VC++
  устанавливаются тихо с официальных ссылок, для Tesseract OCR открывается
  страница загрузки (языки `rus` + `eng`).
- Проверено: тихая установка → запуск из Program Files → API `/api/health` →
  загрузка PDF → 20 показателей и 1 таблица. Ошибок нет.
- Windows 7 не поддерживается этой сборкой (Python 3.12 и актуальные бинарные
  зависимости).
